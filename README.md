# 가락·강서 모바일 경매조회 v18

## 1. 모바일 상단 메뉴 수정

기존 상단 메뉴는 가로형 라디오라 휴대폰에서 오른쪽 메뉴가 가려질 수 있었습니다.

v18은 상단을 **드롭다운 메뉴**로 바꿨습니다.

- 📊 경매조회
- 🧩 등외 해체
- 🔍 세부규격 찾기

휴대폰 폭과 상관없이 `메뉴`를 누르면 세 기능이 모두 보입니다.

---

## 2. ⭐ 즐겨찾기 빠른조회

품목 입력칸을 비우고
`경매 법인 찾기 / ⭐ 즐겨찾기`를 누르면
전체 시장 품목을 긁지 않습니다.

저장한 즐겨찾기 품목만 확인합니다.

기본 예시:
- 표고
- 상추

즐겨찾기는 앱에서 추가/삭제할 수 있습니다.

### 상태

- `✅ 표고 · 강서` : 오늘 강서에서 표고 경매결과 확인
- `⏳ 상추` : 현재 선택 시장에서 오늘 결과 미확인

✅ 품목을 누르면 바로 그 품목 기준 법인 선택 화면으로 넘어갑니다.

그다음:
- 강서청과
- 서부청과
- 농협강서공판장
등 법인을 다시 선택하고 비교표/약세진단을 사용할 수 있습니다.

---

## 3. 속도 구조

즐겨찾기 6개 + 강서만 선택:
- 최대 6개 빠른 확인 요청

즐겨찾기 6개 + 가락/강서:
- 최대 12개 빠른 확인 요청

모두 동시에 처리하고 첫 페이지만 확인합니다.

이전처럼 시장 전체 모든 품목을 페이지 끝까지 읽지 않습니다.

---

## 4. 전체 품목 검색은 보조기능

즐겨찾기 화면 아래:
`전체 품목에서 찾기 (느림)`

필요할 때만 열어서 사용할 수 있습니다.

---

## 5. 즐겨찾기 저장

즐겨찾기는 URL query parameter에도 함께 저장합니다.
같은 앱 URL을 다시 열거나 새로고침했을 때 최대한 유지되도록 했습니다.

기존 기능:
- 직접 품목 입력 검색
- 법인 ✅ / ⏳
- 복수 법인 비교
- 머리/중간/꼬리
- 최근 3/5장 약세진단
- 세부규격 자동보강
- 엑셀 다운로드
