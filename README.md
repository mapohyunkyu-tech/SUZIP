# 가락·강서 모바일 경매조회 v12

v12의 핵심은 **선택한 법인들 사이의 공통품목 비교표**입니다.

예:
- 강서 · 강서청과
- 강서 · 서부청과

두 법인을 동시에 선택하면 상세 탭보다 먼저
`품목(품종) + 단위 + 등급`이 정확히 같은 거래를 자동으로 찾아 한 표에 비교합니다.

## 비교표 예시

양배추(일반) · 10kg · 등외

| 법인 | 건수 | 머리 | 중간 | 중간차이 | 꼬리 | 평균 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 강서 · 강서청과 | 22 | 21,000 | 18,500 | +0 | 15,000 | 18,200 |
| 강서 · 서부청과 | 31 | 22,500 | 19,200 | +700 | 16,000 | 19,000 |

`중간차이`는 사용자가 선택한 법인 중 해당 그룹에 존재하는 **첫 번째 법인**을 기준으로 계산합니다.

## 비교 원칙
- 품목(품종) 정확히 동일
- 단위 정확히 동일
- 등급 정확히 동일
- 이름을 억지로 비슷하다고 합치지 않음
- 단위가 다르면 분리
- 등급이 다르면 분리

## 등외/기타 주의
양배추 등에서 `등외`, `기타`, `없음`처럼 세부규격이 가려진 경우:
- 비교표는 보여주되
- `세부규격 미확인 — 참고가격 비교` 경고를 표시

즉 `42망 ↔ 45망`을 같은 물건으로 단정하지 않습니다.

## 기존 기능 유지
- 장일자 + 품목 검색
- 가락/강서 법인 ✅ / ⏳
- 복수 법인 선택
- 머리/중간/꼬리/평균
- 법인별 실제 경매행
- 세부규격 자동보강(공식 API 키 사용 시)
- 엑셀 다운로드
