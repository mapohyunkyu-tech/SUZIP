# 가락·강서 모바일 경매조회 v16

## 새 기능: 품목을 안 적고 오늘 진행 품목에서 선택

이제 품목을 모를 때 직접 타이핑하지 않아도 됩니다.

### 사용 흐름

1. 장일자 선택
2. 가락 / 강서 시장 선택
3. **품목 입력칸은 비워둠**
4. `경매 법인 찾기 / 오늘 품목 보기`
5. 그 장일자에 실제 경매결과가 확인된 품목 목록 표시
6. 원하는 품목 선택
7. `이 품목 선택하고 법인 다시 찾기`
8. 해당 품목을 취급한 법인은 ✅, 아직 결과 없는 법인은 ⏳ 로 다시 표시
9. 강서청과/서부청과 등 원하는 법인을 다시 선택
10. 비교표 + 약세진단 사용

## 품목 목록 표시

각 품목에:
- 확인된 거래행 수
- 결과가 있는 법인 수
- 시장

을 같이 표시합니다.

예:
`양배추 · 99건 · 3법인 · 강서`

## 중요한 동작

품목 선택 후에는 이전 품목에서 체크했던 법인 선택을 초기화합니다.
그래서 새 품목 기준으로 법인을 **다시 선택**하게 됩니다.

## 새로고침

경매가 진행 중이면 `🔄 품목 새로고침`을 눌러서
새로 올라온 품목을 다시 확인할 수 있습니다.

## 기존 기능 유지

- 직접 품목 입력 검색
- 가락/강서 법인 ✅ / ⏳
- 복수 법인 비교
- 머리/중간/꼬리/평균
- 최근 3/5장 대비 시세 약세 / 우리만 약세 진단
- 공식 세부규격 자동보강
- 엑셀 다운로드
