# 가락·강서 모바일 경매조회 v24

## 이번 버전 핵심

v22를 기준으로 `📚 품위 백과사전`을 추가했습니다.

사진과 품위기록은 Streamlit 세션이 아니라 Supabase에 저장합니다.

- 사진: Supabase Storage `quality-images`
- 기록: `quality_records`
- 사진 메타: `quality_photos`

따라서 Streamlit 앱을 재부팅하거나 재배포해도 Supabase에 저장된 기록은 남습니다.

## 필요한 Streamlit Secrets

```toml
SUPABASE_URL = "https://xxxxxxxx.supabase.co"
SUPABASE_SECRET_KEY = "sb_secret_xxxxxxxxx"
SUPABASE_BUCKET = "quality-images"
```

Secret key는 소스코드나 채팅에 넣지 마세요.

## 품위 백과사전

메뉴에서 `📚 품위 백과사전` 선택.

### 새 품위 기록

- 장일자
- 품목
- 산지
- 품종
- 단위
- 등급
- 내가 본 품위 A/B/C
- 전체샷
- 근접샷
- 추가 사진
- 내 예상가
- 실제 낙찰가
- 품위 메모

를 저장합니다.

품목을 입력하면 품목별 촬영 가이드가 자동 표시됩니다.

## 오늘 기준시세

가락/강서 각 법인의 거래자료에서 법인별 실제 중간가를 먼저 구한 뒤,
그 법인 중간가들의 중앙값을 오늘 기준시세로 사용합니다.

가능하면 아래 순서로 조건을 맞추고,
자료가 없으면 단계적으로 넓힙니다.

A. 같은 산지·품종·단위·등급
B. 같은 산지·단위·등급
C. 같은 단위·등급
D. 같은 산지·품목
E. 같은 품목 전체

화면에는 실제로 어느 단계의 기준을 사용했는지 표시합니다.

## 과거 품위 보정

실제 낙찰가가 입력된 기록은:

`(실제 낙찰가 / 당시 기준시세 - 1) × 100`

으로 당시 시세 대비 프리미엄을 저장합니다.

같은 조건·같은 품위 기록이 3건 이상 쌓이면
오늘 기준시세에 과거 프리미엄을 적용해
오늘 참고 중심가와 참고구간을 보여줍니다.

## 현재 하지 않는 것

v24는 사진 자체를 AI가 자동 판독하지 않습니다.
사진 유사도 기능은 실제 품위 사진 데이터가 충분히 쌓인 뒤 붙이는 것이 안전합니다.

현재 `건수`는 공개 경매행 수이지 실제 박스/망 수량(QTY)이 아닙니다.
