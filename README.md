# 가락·강서 모바일 경매조회 v20

## 수정 이유

직접 `아스파라거스`를 검색하면 서울청과가 나오는데,
즐겨찾기 아스파라거스는 `⏳`처럼 보이던 문제를 수정했습니다.

원인은 즐겨찾기와 직접검색의 조회 방식이 달랐기 때문입니다.

### 기존 즐겨찾기
- 시장 전체
- 법인코드 공란
- 첫 페이지만 확인

### v20 즐겨찾기
직접 품목 검색과 똑같이:
- 실제 법인 목록 확인
- 즐겨찾기 품목 × 법인별로 `probe_company()` 실행
- 한 법인이라도 결과가 있으면 ✅
- 확인된 법인명도 바로 표시

따라서 직접 검색에서:
`아스파라거스 → 가락 · 서울청과`

가 확인되면 즐겨찾기에서도:
`✅ 아스파라거스 · 1법인`
`확인 법인: 가락 · 서울청과`

처럼 나와야 합니다.

## 표시 변경

`⏳`는 '로딩 중'으로 오해할 수 있어서 없앴습니다.

- `✅ 품목 · N법인` = 오늘 결과 확인
- `— 품목 · 미확인` = 조회는 끝났지만 결과 미확인

실제 로딩 중에는 별도의 spinner만 표시됩니다.

## 기존 기능 유지
- 즐겨찾기 추가/삭제
- 오늘 경매여부 확인 버튼
- 직접 품목검색
- 법인 선택
- 법인 비교표
- 약세진단
- 모바일 메뉴
