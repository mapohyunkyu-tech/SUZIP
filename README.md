# 가락·강서 모바일 경매조회 v7

v6에서 발견된 오탐을 수정한 버전입니다.

## 가장 중요한 수정
예전에는 `고구마`를 검색해도 대아청과의 양배추 시황에 있는 `42망`이 잡혔습니다.

v7은:
- 검색한 품목명이 실제 페이지에 있어야 함
- 그 품목명 주변 구간에서만 42/45/4수 등을 직접 단서로 인정
- 품목과 무관한 `spec`, `grade` 같은 사이트 구조 필드는 별도 영역으로 분리
- 즉 `고구마` 검색 결과에 양배추의 42망을 직접 단서로 섞지 않음

## 법인별 자동검사
가락:
- 대아청과
- 동화청과
- 중앙청과
- 한국청과
- 서울청과
- 농협가락공판장

강서:
- 서부청과
- 강서청과
- 농협강서공판장

각 법인 공개 사이트의 시작 페이지에서
시세/경매/가격 관련 같은 도메인 링크를 1단계 자동 탐색합니다.

## 결과 구분
- `품목 직접단서`: 품목과 실제로 연결된 42망/45망/4수/숫자코드
- `가격후보`: 해당 단서 주변에 같이 나온 가격 숫자 후보
- `사이트 구조/필드 후보`: size/spec/grade 등. 품목 직접증거는 아님
- `품목발견 —`: 검사 페이지에 그 품목이 없으므로 다른 품목 규격은 제외됨

## 주의
- 공개 페이지와 공개 JS만 검사합니다.
- 로그인/권한 우회는 하지 않습니다.
- 코드 `[1]`을 42망처럼 임의 매핑하지 않습니다.
- Streamlit Cloud에서 특정 법인 사이트가 막히면 해당 법인은 접속 실패로 표시됩니다.
