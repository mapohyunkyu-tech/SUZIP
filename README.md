# 가락·강서 모바일 경매조회 v11

이번 버전은 **경매결과와 세부규격 보강을 한 화면에 합친 버전**입니다.

## 📊 경매조회
기존처럼:
- 장일자 + 품목 검색
- 가락/강서 법인 상태 ✅ / ⏳
- 법인 선택
- 실제 공개 경매결과
- 머리/중간/꼬리/평균

을 먼저 보여줍니다.

그 아래 `🧩 확인된 세부규격`이 자동으로 붙습니다.

## 세부규격 자동보강
상단 `🧩 세부규격 자동보강 설정`에서:
1. 자동보강 ON
2. 농림축산식품 공공데이터 API 키 입력

그러면 같은:
- 장일자
- 시장
- 법인
- 품목

의 공식 데이터를 찾아 붙입니다.

### 우선 확인
`도매시장 정산 가격 정보`에서 직접 내려오는:
- STD
- SIZENAME
- LVNAME
- 최저/최고/평균
- 총물량

을 확인합니다.

### 실제 거래행
법인코드가 연결되면 `도매시장 원천데이터 정산 가격`을 다시 불러와:
- 단량
- 단위
- 포장
- 크기
- 등급
- 물량
- 실제 경락가
- 산지
- 낙찰시간

을 거래행 단위로 표시합니다.

## 중요한 원칙
공사 모바일 경매행과 공식 정산/원천 행을 억지로 1:1 매칭하지 않습니다.
같은 장일자·시장·법인·품목에 대해 **공식 원천에서 실제 확인된 규격만** 별도 보강합니다.

규격이 없으면 추측하지 않습니다.

## API 키
농림축산식품 공공데이터포털의 OpenAPI 키를 사용합니다.
키는 채팅에 보내지 말고 앱 입력칸 또는 Streamlit Secrets에 넣으세요.

Streamlit Secrets 예시:

```toml
MAFRA_API_KEY = "발급받은키"
```
