# 가락·강서 모바일 경매조회 v6

v5의 실사용 경매조회에 **휴대폰용 `🔍 세부규격 찾기`**를 추가한 버전입니다.

## 경매조회
- 장일자 + 품목 검색
- 가락/강서 법인별 ✅ 결과 있음 / ⏳ 아직 없음
- 재로딩
- 복수 법인 선택
- 품종 → 단위 → 등급 → 머리/중간/꼬리/평균
- 실제 경락가/출하지
- 엑셀 다운로드

## 세부규격 찾기
휴대폰에서 바로 공개 페이지를 검사합니다.

찾는 흔적:
- 42망 / 45망 / 40망 / 38망 등
- 4수 / 4개들이 / 4포기
- size / spec / standard / grade / class / level / unit
- size_cd / spec_cd / grade_cd 등의 필드
- 품목명 주변의 [1]~[9] 내부 코드 후보
- 페이지가 직접 불러오는 동일 도메인 공개 JS

기본 프리셋:
- 서부청과 모바일 채소
- 대아청과 시황 예시
- 직접 공개 URL 입력

## 주의
- 로그인 우회, 권한 우회, 비공개 경로 추측을 하지 않습니다.
- `[1]~[6]`을 42/45망으로 임의 매핑하지 않습니다.
- 직접 규격명과 코드가 함께 나타나는 증거가 있어야 매핑합니다.
- Streamlit Cloud에서 특정 시장 사이트 접속이 막히면 PC 정밀검사(HAR)가 필요할 수 있습니다.

## 배포
GitHub에 아래를 업로드:
- app.py
- requirements.txt
- .streamlit/config.toml

Streamlit Community Cloud에서 Main file path를 `app.py`로 지정해 배포합니다.
