# 가락·강서 모바일 경매조회 v9

v8에서 `고구마: 품목발견 ✅ / 직접단서 0 / 검색폼 4 / 페이지 39`가 나온 문제를 보완했습니다.

## 핵심 변화
이제 미리 알고 있는 규격명만 찾지 않습니다.

검색한 품목이 들어간:
- 표 행(tr)
- 리스트(li)
- 문단(p)
- option/select
- 주변 HTML 문맥

을 **원문 그대로** 모아서 보여줍니다.

예를 들어 고구마 페이지가 `긴특` 대신 숫자코드나 다른 명칭을 쓰더라도:
- 원문행
- 숫자/단위 후보
- 등급/토큰 후보
- select option_text / option_value
를 확인할 수 있습니다.

## 기존 기능 유지
- 공개 검색폼 자동 제출
- 품목 상세페이지 추적
- 양배추 42/45망 등 직접단서
- 고구마 긴특/공중 등 직접단서
- 표고 C/T 등
- 다른 품목 규격 오탐 방지
- 로그인/권한 우회 없음

## 해석
- 직접단서 0이어도 `원문행`이 있으면 아직 가능성이 있습니다.
- option 값에 숫자코드가 있으면 그 코드를 규격명과 연결할 실마리를 찾을 수 있습니다.
- 원문행/option에도 세부정보가 전혀 없으면 해당 공개 경로에서는 세부규격이 내려오지 않을 가능성이 큽니다.
