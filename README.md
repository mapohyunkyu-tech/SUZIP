# 가락·강서 모바일 경매조회 v8

v7의 단순 링크 탐색을 넘어, 각 법인의 **공개 검색폼에 품목명을 실제로 넣어 조회**하고
그 검색결과의 품목 상세페이지까지 추적하는 정밀 검사 버전입니다.

## 세부규격 정밀찾기
- 공개 검색폼 자동 감지
- 검색폼 GET/POST 자동 조회
- 검색결과에서 해당 품목 링크 우선 추적
- 관련 시세/경매 페이지 최대 2단계 탐색
- 다른 품목 규격 오탐 방지

## 품목별 직접단서
- 양배추: 36/38/40/42/45망 등, 4수/4개들이
- 고구마: 긴특/긴상/긴중/긴하/공특/공중/공하/왕왕/특상/상중 등
- 감자: 왕왕/왕특/특대/대특/특상/상중 등
- 표고: C/T, CT, P-BOX, PP대, 상자

## 안전 범위
- 공개 페이지와 공개 검색폼만 사용
- 로그인/권한 우회 없음
- 쓰기/삭제/주문/예약/회원 관련 폼은 자동 제외
- 같은 도메인의 공개 페이지까지만 추적
- 사설/로컬 IP 요청 차단

## 법인
가락:
- 대아청과
- 동화청과
- 중앙청과
- 한국청과
- 서울청과
- 농협가락공판장

강서:
- 서부청과
- 강서청과
- 농협강서공판장

## 결과 해석
- 직접단서 > 0: 해당 품목 주변에서 세부규격 표현 발견
- 품목발견 ✅ / 직접단서 0: 품목은 찾았으나 세부규격 표현은 못 찾음
- 검색폼 > 0: 실제 공개 검색폼에 품목명을 넣어 조회까지 성공
- 접속 ❌: Streamlit Cloud에서 해당 사이트 접속이 막혔을 수 있음
