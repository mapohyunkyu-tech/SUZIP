# 가락·강서 모바일 경매조회 V13 → V14 (기존 앱 업그레이드)

**새 앱이 아닙니다. 기존 app.py를 유지한 채 `📈 기간 시세분석` 기능만 추가했습니다.**

## 기존 기능 그대로 유지
- 📊 경매조회: 날짜·품목·시장 및 복수 법인 선택
- 품종/단위/등급별 머리·중간·꼬리·평균, 원자료, 엑셀 다운로드
- 🧩 등외 해체 (공식 공공데이터 활용)
- 🔍 세부규격 찾기 (법인별 공개 페이지 정밀검사)
- 세부규격 자동보강 설정 및 기존 사용 흐름

## V14 새 기능
1. 같은 기존 화면 상단에서 `📈 기간 시세분석` 메뉴를 선택합니다.
2. 시장(가락/강서), 법인(예: 대아청과), 품목(예: 양배추)을 선택합니다.
3. 시작 장일자 2026-10-10, 종료 장일자 2026-10-17 등을 선택합니다.
4. 원하면 중량 필터 `8kg`를 입력합니다. 없으면 비워둡니다.
5. `선택 법인 기간 시세 조회` 버튼을 누릅니다.
6. 품종·정규화 중량/포장·원본 등급을 골라 날짜별 최고·평균·최저가 그래프를 봅니다.
7. 실제 수집된 일별 수치 CSV, 원본 거래표, 수집일별 실패/무거래 상태를 확인할 수 있습니다.

## 데이터·해석 주의
- 소스: 기존 가락시장 공개 경매 결과 사이트 `temp.garak.co.kr` (기존 코드 재사용).
- 실제 사이트에서 데이터를 받을 수 있는지 현 실행 환경에서는 검증하지 못했습니다.
- 가져오지 못한 날짜는 **0원으로 대체하지 않습니다**.
- 평균은 경락 건별 단순 평균입니다. 공개 표의 개별 수량이 없으므로 물량가중평균이 아닙니다.
- 원본 등급이 `등외/기타` 등으로 표시되면 42망/45망 같은 내부 세부규격은 알 수 없습니다.
- `8kg` 필터는 `8kg/8.0kg/8kg망/8kg상자`처럼 접미 포장 후보를 포함하나 서로 다른 포장은 개별 그래프로 표시합니다.
- 최대 31일 구간을 지원합니다.
