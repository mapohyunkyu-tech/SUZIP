# 가락·강서 모바일 경매조회 v19

## v18 오류 대응

v18은 즐겨찾기를 추가하면 Streamlit rerun 직후 바로 경매여부 조회가 실행됐습니다.
그래서 사용자는 `추가`만 했는데도 로딩이 시작됐고,
상태 전환이 겹치면 이후 품목/법인 화면이 불안정해질 수 있었습니다.

v19에서는 이 두 동작을 완전히 분리했습니다.

### 즐겨찾기 추가/삭제
- 네트워크 조회 없음
- 즉시 저장만 함
- 로딩하지 않음

### 오늘 경매여부 확인
- `⚡ 오늘 경매여부 확인` 버튼을 눌러야 조회 시작
- 즐겨찾기 품목만 조회
- 결과를 session_state에 보관
- ✅ 품목을 누르면 해당 품목 기준 법인선택으로 이동

## 오류 격리

법인 상세, 법인 비교표, 약세진단을 각각 try/except로 감쌌습니다.
한 기능의 오류 때문에 전체 앱이 죽지 않고
해당 위치에 실제 오류 메시지를 표시합니다.

## 기존 기능 유지
- 모바일 드롭다운 메뉴
- 직접 품목 검색
- 즐겨찾기 추가/삭제
- 느린 전체품목 보조검색
- 법인 ✅ / ⏳
- 법인 비교표
- 최근 3/5장 약세진단
- 세부규격 자동보강
- 엑셀 다운로드
