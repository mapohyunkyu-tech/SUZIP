# 가락·강서 모바일 경매조회 v31

## 품위 기록 방식
- 특1 ~ 특5
- 상1 ~ 상5
- 중1 ~ 중5

의미:
- 1 = 해당 큰 등급 안에서 최상
- 5 = 다음 큰 등급으로 내려가기 직전

## 가락 머리 대비
품위 백과사전에서는 `가락 동일단위 머리 자동 계산`을 사용합니다.

비교 우선순위:
1. 같은 품종 + 단위 + 공식등급
2. 같은 품종 + 단위
3. 같은 단위 + 공식등급
4. 같은 단위

출하지는 가락 시장 전체 머리를 잡을 때 필터하지 않습니다.
다른 중량/포장은 섞지 않습니다.

실제 낙찰가를 입력하면:
- `가락 머리 대비 82.0%`처럼 바로 표시
- Supabase에는 기존 `premium_pct` 필드에 머리 대비 차이를 저장
- 같은 품목·단위·품위 기록이 3건 이상 쌓이면
  과거 비율을 이용해 오늘 가락 머리 대비 참고 범위를 표시

## 원산지/출하지
- 출하지와 원산지는 별개
- 원산지는 사용자가 아는 경우만 참고 기록
- 가락 머리 계산에는 원산지를 사용하지 않음

## 비용
OpenAI API를 사용하지 않습니다.
기존 Supabase 저장만 사용합니다.
