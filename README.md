# 가락·강서 모바일 경매조회 v33

## 백과사전 수정 기능

저장된 품위 기록을 펼치면 `✏️ 기록 수정` 버튼이 있습니다.

수정 가능:
- 장일자
- 품목
- 출하지
- 품종표기
- 단위/포장
- 공식 등급표기
- 품위: 특/상/중 × 1~5
- 원산지 참고
- 실제 낙찰가
- 메모

장일자·품목·품종·단위를 수정하면 기존 기준값을 그대로 쓰지 않고,
수정된 조건으로 `가락 동일단위 전체 머리`를 다시 계산한 뒤 저장합니다.

## 백과사전 삭제 기능

`🗑️ 기록 삭제` → `정말 삭제합니다` 체크 → `❌ 영구 삭제`

삭제 시:
1. Supabase Storage의 연결 사진 삭제
2. quality_records 기록 삭제
3. quality_photos 메타데이터는 FK ON DELETE CASCADE로 삭제

즉 목록에서만 숨기는 것이 아니라 실제 백과사전 기록과 사진을 삭제합니다.

## 유지 기능

- 특1~특5 / 상1~상5 / 중1~중5
- 가락 전체/특/상/중 머리 대비 표시
- 촬영 또는 앨범 사진 등록
- Supabase 영구 저장
- OpenAI API 없음
