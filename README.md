# 가락·강서 모바일 경매조회 v32

## 핵심 수정: '몇 등급 머리 대비인지' 명확히 표시

v31에서는 `가락 머리 대비 47.6%`처럼 보여서,
그 기준이 특 머리인지 상 머리인지 헷갈릴 수 있었습니다.

v32는 기준을 분리해서 표시합니다.

예:
- 가락 전체 동일단위 머리 대비 47.6%
- 가락 특 머리 대비 47.6%
- 가락 상 머리 대비 72.1%
- 가락 중 머리 대비 93.4%

## 기본 저장 기준

Supabase에 저장되는 기본 benchmark는 항상:

`가락 같은 단위 전체등급 최고가(전체 머리)`

입니다.

즉 사용자가 공식등급 칸에 `상`을 적더라도
기본 비율이 상 머리로 바뀌지 않습니다.

이렇게 해야 `특1~특5 / 상1~상5 / 중1~중5` 기록들이
모두 같은 기준으로 비교됩니다.

## 공식 등급별 머리

특/상/중 머리는 엄격하게 해당 공식등급 자료에서만 계산합니다.

- 특 자료가 없으면 특 머리는 `자료없음`
- 상 자료가 없으면 상 머리는 `자료없음`
- 다른 등급이나 전체값으로 몰래 대체하지 않음

## 품위 선택

- 특1 ~ 특5
- 상1 ~ 상5
- 중1 ~ 중5

실제 낙찰가를 넣으면 선택한 큰 등급 기준도 강조합니다.

예:
`선택 품위 상2 → 가락 상 머리 대비 72.1%`

## 기타

- 다른 중량/포장 가격은 섞지 않음
- 출하지와 원산지는 별개
- OpenAI API 없음
- 기존 Supabase 사진/기록 저장 유지
