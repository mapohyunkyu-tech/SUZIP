# 가락·강서 모바일 경매조회 v27

## 사진 입력 개선

품위 백과사전의 전체샷과 근접샷을 각각 두 방식으로 넣을 수 있습니다.

- 📷 지금 촬영
- 🖼️ 앨범에서 선택

즉 미리 찍어둔 사진도 그대로 사용할 수 있습니다.

### 사용 순서
1. `① 전체샷` 선택
2. `지금 촬영` 또는 `앨범에서 선택`
3. `전체샷 저장`
4. `② 근접샷` 선택
5. `지금 촬영` 또는 `앨범에서 선택`
6. `근접샷 저장`
7. 두 장 미리보기 확인
8. Supabase 영구 저장

모바일 카메라 충돌 방지를 위해 카메라는 여전히 한 번에 하나만 렌더링합니다.

## 유지 기능
- Supabase DB + Storage 영구 저장
- 품목별 촬영 가이드
- 오늘 자동 기준시세
- 실제 낙찰가 / 당시 시세 대비 프리미엄 저장
- 품목+산지 즐겨찾기
- 산지·품종별 법인 비교
