# 가락·강서 모바일 경매조회 v25

## 모바일 카메라 수정

v24는 `전체샷`과 `근접샷`에 `st.camera_input`을 동시에 2개 띄웠습니다.
일부 모바일 브라우저에서는 카메라 스트림을 동시에 2개 열지 못해 한쪽이
`This app would like to use your camera` 상태로 막힐 수 있습니다.

v25는 카메라를 한 번에 하나만 렌더링합니다.

### 촬영 순서
1. `① 전체샷` 선택
2. 촬영
3. `전체샷 저장`
4. `② 근접샷` 선택
5. 촬영
6. `근접샷 저장`
7. 두 장이 모두 미리보기로 보이면 Supabase 영구 저장

필요하면 각 사진은 `다시 찍기`로 교체할 수 있습니다.

## 나머지 기능
- Supabase DB + Storage 영구 저장
- 품목별 촬영 가이드
- 오늘 자동 기준시세
- 실제 낙찰가/당시 시세 대비 프리미엄 저장
- 품목+산지 즐겨찾기
- 산지·품종별 법인 비교
