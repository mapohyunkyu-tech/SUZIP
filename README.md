# 가락·강서 모바일 경매조회 v3

## 화면 상태

검색하면 선택한 시장의 법인이 전부 보입니다.

- `✅ 법인명` = 오늘 해당 품목 경매결과가 올라온 법인
- `⏳ 법인명` = 아직 해당 품목 경매결과가 없는 법인
- `✅` 법인만 누를 수 있습니다.
- `⏳` 법인은 비활성화됩니다.
- 우측 `🔄 재로딩`을 누르면 최신 상태를 다시 확인합니다.

예:

### 가락시장
✅ 서울청과
✅ 중앙청과
✅ 동화청과
⏳ 한국청과
⏳ 농협(공)

### 강서시장
✅ 서부청과
⏳ 강서청과

## 법인 선택

`✅`는 "경매결과 있음"이라는 상태 표시입니다.

법인을 실제로 선택하면 버튼 색이 강조됩니다.
다시 누르면 선택이 해제됩니다.
여러 법인을 동시에 선택할 수 있습니다.

선택된 법인은 아래에서 탭으로 나뉩니다.

각 탭:
품종 → 단위 → 특 → 상 → 보통 → 기타

표시값:
- 머리 = 최고가
- 중간 = 실제 경락값 중 중앙 순번 가격
- 꼬리 = 최저가
- 평균 = 건별 단순평균

## 재로딩

경매가 끝난 뒤 결과가 아직 사이트에 안 올라온 법인은 `⏳`입니다.
결과가 등록된 뒤 `🔄 재로딩`을 누르면 `✅`로 바뀌고 선택할 수 있습니다.

## 시장 구분

법인은 항상 시장과 함께 구분합니다.

예:
- 가락 · 한국청과
- 강서 · 서부청과
