# 가락·강서 모바일 경매조회 v13

v12에서 두 법인을 선택해도 비교표가 안 보이던 문제를 수정한 버전입니다.

원인:
- v12가 `품목(품종) + 단위 + 등급`을 너무 엄격하게 똑같아야 비교하도록 잡았음
- 실제 공개자료는 `10kg / 10.0kg`, `등외 / 기타 / 없음`처럼 표기가 다를 수 있음

v13:
- 법인 2곳 이상 선택하면 `📊 선택 법인 비교` 영역이 항상 먼저 표시
- `10kg / 10.0kg / 10.000kg`을 같은 단위로 정리
- `등외 / 기타 / 없음 / 무등급`은 `세부등급 미확인`으로 묶어 비교
- 실제 품종/단위/등급 원문도 표에 같이 표시
- 공통 단위+등급 그룹이 하나도 없어도 각 법인 전체 머리/중간/꼬리/평균 요약을 표시
- 세부규격 미확인 그룹은 42/45망, 4내/4수 등이 섞였을 수 있다고 경고

기존 기능:
- 가락/강서 법인 상태
- 복수 법인 선택
- 실제 경매결과
- 머리/중간/꼬리/평균
- 공식 세부규격 자동보강
- 엑셀 다운로드
