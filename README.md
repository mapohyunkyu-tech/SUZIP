# 가락·강서 모바일 경매조회 v10

이번 버전의 핵심은 **`등외 해체`** 입니다.

공사 모바일 경매화면에서 `등외`, `기타`, `-`처럼 뭉개져 보이는 거래를
농림축산식품부 공식 **도매시장 원천데이터 정산 가격**에서 다시 읽어서
다음 필드를 분리합니다.

- 단위중량 (`DANQ`)
- 단위코드 (`DANCD`)
- 포장코드 (`POJCD`)
- 크기코드 (`SIZECD`)
- 등급코드 (`LVCD`)
- 물량 (`QTY`)
- 경락가 (`COST`)
- 품목 / 품종
- 산지
- 낙찰시간
- 법인 / 시장

그리고 공식 코드 API를 붙여:
- 등급 코드 → 특 / 상 / 보통 / 4등 / 5등 ...
- 포장 코드 → 상자 / P-BOX / PE대 / PP대 / 그물망 ...
- 크기 코드 → 1개(내,뿌리) / 2개 / 3개 / 4개 / 5개 / 30내 / 40내 ... 등
- 단위 코드 → g / kg / ton(M/T) ...

처럼 사람이 보는 이름으로 바꿉니다.

## 화면

### 📊 경매조회
기존 공사 모바일 경매결과:
- 가락/강서
- 법인 상태 ✅ / ⏳
- 머리 / 중간 / 꼬리
- 원 경락행

### 🧩 등외 해체
두 모드가 있습니다.

1. **원천 정산 · 등급+크기 해체**
   - 가장 중요한 모드
   - 포장/크기/등급을 별도 코드에서 복원
   - `특/상/보통 외만` 필터
   - 같은 등외라도 규격별로 가격을 따로 집계
   - 머리/중간/꼬리/평균
   - CSV 저장

2. **실시간 경락 · 공개규격 확인**
   - 경매 직후 빠르게 확인
   - 실시간 API의 `STD` 원문을 그대로 표시
   - 법인별 규격 가격 비교
   - 실시간에서 크기가 생략돼 있으면 정산 후 원천자료로 재확인

### 🔍 세부규격 찾기
기존 법인 홈페이지 공개소스 조사 기능.

## 공식 API 키

`🧩 등외 해체`는 농림축산식품 공공데이터포털의 OpenAPI 키가 필요합니다.

대상 서비스:
- 도매시장 원천데이터 정산 가격
- 도매시장 실시간 경락 정보
- 법인 코드
- 등급 코드
- 단위 코드
- 포장 코드
- 크기 코드

앱 입력칸에 직접 넣거나 Streamlit secrets에:

```toml
MAFRA_API_KEY = "발급받은키"
```

를 등록하세요.

**API 키는 채팅에 보내지 않는 것을 권장합니다.**
